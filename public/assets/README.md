# Portfolio assets

Replace the placeholders in this folder with your own approved assets.

- `Pritam-Sarkar-CV.pdf` — the approved CV PDF used by the Download CV links.
- `profile/pritam-sarkar.jpg` — the supplied portrait used by the current build.
- `profile/pritam-sarkar-formal.jpg` — the supplied formal portrait used in the Formal portrait mode.
- `projects/` — optional project screenshots or diagrams.
- `publications/` — optional publication thumbnails.
- `conferences/` — optional conference photos.

The app uses CSS/SVG visuals when these assets are absent, so no fabricated personal media is required.
